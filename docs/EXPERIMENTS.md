# 最终场景、指标与实验复现

## 数据版本

最终仅使用eos-final-v3。60正式＋6联调，三档为10星20任务、20星80任务、50星200任务，时域1800秒、无地面站；每档正式四负载各5份，15正式家族＋3独立联调家族，家族内变体相关。

轨道独立生成，倾角35°—110°、高度约550—1050km，小/中/大最小无向轨道面夹角分别10°/8°/6°。任务先验独立于轨道，包含球面背景与椭圆区域热点；最终按可达性/公开资源时间压力选择，不宣称全球iid随机或真实业务。保留完整先验与种子，并验证更改orbit_seed不改变先验点位。

普通组保持宽松地理覆盖，数量自然浮动；高冲突按组长许可单独作为区域集中极端组。约5.5%请求没有完整窗口，单独记录可达率，不修改TCR分母。新数据的绝对角范围yaw/roll±180°、pitch±90°，生成窗口额外限离天底角30°，保留旧课程姿态解释和遮挡。工程采样不等于连续证明。

v1全部偏南，v2轨道成对且目标贴近轨迹，均停用。旧1140次及v2中止的84成功/11取消，仅为历史记录，不拼入v3。v3初稿高冲突梯度不足，调整独立区域权重；资源过载组统一存储设0.0012GB，原字节/失败日志/变换源均保留，不按算法成绩挑数据。

## 指标与统计单位

| 指标 | 定义与方向 |
|---|---|
| TP | 已完成任务优先级之和，越高越好 |
| TCR | 完成不同任务数/全部请求数；空请求返回0 |
| BD | clamp(1-sum(abs(Ls-mean(L)))/(2*全部请求曝光时长),0,1)，越高越均衡；结合TCR判断 |
| TM | (已完成开始时刻距场景起点的等待之和＋未完成数×时域)/(时域×请求数)，越低越好 |
| RT | 算法求解时间，不是排队墙钟或曝光时长 |

综合分=70×TCR＋20×收益比例＋10×(1−TM)，总优先级为0时收益项0，RT不计分。RV仅保留历史字段，单种子不产生稳健性结论。

先在来源家族内平均四变体，再对15家族等权平均；三档/四负载另列。不要将60变体称60独立来源，不把任务加权汇总比率与等权场景TCR混用。缺失值不得填0；并行RT受资源争用影响，不是严格串行速度比较。

## 最终实际执行

60场景×19算法=1140次，seed42、每算法60秒、完成率目标、earliest、默认约束、completion_first初始模型；LAVIS固定lavis-v4-opportunity＋expanded＋multistart，未重训。全程Worker上限8，1140次SUCCEEDED且指标有效，每算法60次，无MIP/PPO。

已核对完整笛卡尔矩阵、1140份计划/任务唯一性/TP/TCR/CSV，以及独立重算19算法家族汇总。按TCR本次SA最高，按综合分EDF最高，LAVIS未优于多数传统基线；不从单种子小差异声称显著领先。

实验ZIP只包含元数据/原始数据/统计数据，无论文说明。冻结了实际执行源码、模型、环境、协议、场景和哈希；ZIP CRC与逐文件校验通过。最终提交只更新发布文档/交付记录，实际求解源码未变，实验内快照仍是执行时身份，不重写成后来的Commit。

## 再实验与重训

先用smoke检查部署，再冻结代码、模型、场景、预算和并发。多种子/多机器测量另行标明，保留全部失败/超时，不用重跑成功替换原记录。看过测试集以后继续调参，不能再称其未见最终测试。

训练入口scripts/train_lavis_opportunity.py collect|train；使用可选公开训练资源及来源隔离划分，不使用最终测试。为新训练分配新model_id/目录，不覆盖v4。v3实际生成源与独立验证程序保存在场景包generator_sources，v1旧生成工具不生成最终场景。
