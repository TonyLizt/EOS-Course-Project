# 最终展示视频：建议讲稿与操作清单

建议时长8—10分钟。六个评分项等权，分别给出可见证据；无需照读全部技术细节。组员可分段讲解，录制前先完整彩排一次。

## 录制前

- 使用发布版本及配套资源包，先运行部署/检查脚本，确认模型、Orekit数据与场景哈希。
- 日常演示用smoke联调场景；正式测试成绩只能展示冻结后实际跑出的报告，不用演示场景充当论文测试集。
- 清空浏览器无关标签，显示完整桌面窗口；准备一份成功的甘特图/Cesium回放以免构建等待占满视频。
- 预先确认活动实验为0。故障操作全部在独立“守护演示”页完成，不结束正式实验后端。
- 准备单Worker与双Worker同批工作负载的真实测量（如尚未测量，不口头给出加速比）。

## 00:00—00:50 背景、分工、操作系统类比

操作：打开课程导览，展示两层调度图和概念对应表。

讲稿：“这是《操作系统课程设计》的多星观测调度实验平台。观测请求对应作业，卫星载荷对应服务资源，曝光时间对应服务时间，转向与稳定对应切换开销。我们同时实现了实际的Controller、独立Worker、IPC、锁与数据库事务。一个Worker求解整份卫星计划，不代表一颗卫星。”

“我们基于EOS-Bench扩展课程系统，保留开源来源。李泽同负责总体集成和LAVIS，何明涛负责Worker/IPC与DARTIS，刘懋兴负责数据协议与CAABS，梁兆榮负责前端可视化、Daemon与RABAS。”

## 00:50—02:10 可运行与功能完整性

操作：展示启动终端与服务已连接；选择联调数据源、小场景、两种算法、预算/种子及输出位置，提交实验；切到运行管理。

讲稿：“源码和运行资源分开放置，场景和输出路径可以配置。提交后系统创建独立算法运行，Controller从队列派发到Worker；Worker返回候选计划，再独立核验并以事务保存。”

展示：状态变化、真实PID、求解/核验耗时、运行事件、成功计划及配置。算法预算是上限，不要求每种算法耗尽全部预算。

## 02:10—03:10 功能完整性与用户体验

操作：比较页选择算法，点击TCR/综合分/耗时表头排序；打开甘特图并缩放查看任务；切到已构建Cesium回放，播放、选中任务/卫星。导出统计CSV或ZIP并展示内容。

讲稿：“比较以相同场景、约束、预算及并发条件分组。导出包含配置、逐运行指标和任务明细，便于同学统计。长列表内部滚动，配置、管理和比较分开，减少一页选项堆积。”

说明指标：TCR为完成任务比例，TP为完成任务优先级收益，TM为带未完成惩罚的归一化等待指标，RT为算法求解时间。综合分70%完成率、20%收益比例、10%时效；RT另列，不混入综合分。

## 03:10—04:15 性能优化

操作：展示并发设置、多个不同Worker PID及任务队列；切到预先测量的同批串行/并行结果表。

讲稿：“系统将计算放到独立进程，避免网页请求同步等待求解；并发槽位有上限，避免无控制地占满资源。我们用整批完成时间、成功数、资源占用评价并发效果。单算法RT和整批墙钟时间是不同指标，不能直接拿并发下的RT判断算法快慢。”

如果没有真实测量：只演示并行能力，不声称固定倍数提速。资源占用用真实进程工具或已测报告，不画假CPU曲线。

## 04:15—06:20 可靠性与守护能力（重点）

操作：进入独立守护演示页，按①启动→②结束Worker→③结束演示后端→④停止清理。

讲稿：“老师要求的守护能力，我们用独立Daemon进程实现。这里不是网页动画：临时实例真实启动Daemon、Controller和Worker，使用双Pipe、文件锁和SQLite。为便于控制演示，Worker执行等待作业，故障演示不计算卫星指标。”

“结束Worker后，当前运行被明确判为失败，资源被回收，下一作业接续，Daemon重启次数不变。这体现故障隔离。”

“结束演示后端后，Daemon PID不变，经过退避启动新Controller，恢复次数加一。旧运行记录CONTROLLER_RESTART，排队作业继续。恢复的是服务，不是算法断点续算。”

“最后正常停止，不再自动拉起，并清理临时目录。此页与主实验实例隔离，所以真实实验数据不受影响。”

## 06:20—07:10 其他可靠性证据

操作：用联调实验展示取消或短预算超时记录、错误原因、已提交成功结果仍可查询；展示测试摘要与数据校验报告。

讲稿：“取消、超时、失败和成功有明确终态；失败不能提交为成功计划。输入和来源记录带哈希，候选还要通过独立核验。并发和恢复用真实进程测试，不能只凭HTTP200认为系统健康。”

## 07:10—08:30 创新与最终实验

操作：展示四种小组算法的原理摘要，以及最终场景矩阵和真实统计图（生成并测试后补入）。

讲稿：“我们把FCFS、SJF、优先级、EDF等策略迁移到具有窗口和切换成本的卫星场景。自研方法包括DARTIS动态插入、RABAS任务包竞价、CAABS冲突感知束搜索，以及LAVIS学习型候选价值排序。所有方法通过统一接口与同一核验规则比较。”

“最终包包含小中大规模与高冲突、资源紧张等负载；同源变体按家族管理，测试数据不用于重训或选型。我们如实展示优劣，不把传统算法的好结果改名成自研成果。”

此处只填冻结实验真实结果，不预设LAVIS或其他小组算法一定获胜。

## 08:30—09:00 交付结束

操作：展示仓库README、说明.txt、部署命令、资源包和哈希清单。

讲稿：“源码、部署说明、成员分工与开源来源在仓库中；无法随Git分发的场景、模型和物理数据另有资源包。系统已演示配置、执行、核验、统计、回放和故障恢复。”
