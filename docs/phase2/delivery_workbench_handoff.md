## 4. 面向统计的导出

### 网页使用

1. 在实验管理勾选实验，可跨分页选择；“清空选择”只取消勾选。
2. “统计CSV”每行一次算法运行，适合Excel/pandas；“统计数据包ZIP”提供完整统计材料。
3. 详情页和结果比较页可直接导出当前实验。
4. 默认仅导出当前成员；勾选“包含已移除算法的历史记录”可追溯旧运行，正式统计时按removed_at筛选。
5. 临时对照不持久入库，不纳入持久统计包；需要留档请创建正式的对照实验。

### API

`POST /api/statistics/export`

```json
{"experiment_ids":["实验ID"],"format":"zip","include_removed":false}
```

format为csv或zip；ID去重。不存在的实验404，空列表/非法格式422，超过500次运行、10万条明细或64MiB限制413，提示分批导出。每次最多选择100个实验。压缩在Controller终态锁外进行，仅查询快照，不增加导出数据库记录或磁盘临时文件。

### ZIP文件

| 文件 | 内容 |
|---|---|
| summary.csv | 每行一次运行：状态、错误、条件、谱系、场景/代码/模型SHA、种子、预算、参数、核验、指标和评分 |
| aggregates.csv | 按同条件与算法参数/权重分组，跨种子给出样本数、均值和样本标准差 |
| assignments.csv | 有效运行逐任务明细；不重复汇总指标 |
| configurations.json | 配置快照，省略本机scenario_path/output_root |
| manifest.json | 导出范围、时间、数量和各文件SHA-256 |
| README.md | 包内统计说明 |

CSV为UTF-8 BOM，稳定英文列名；TCR/BD/TM保留原始比例，RT为秒。Excel文本公式前缀转义，真实数值不受影响。

### 统计约束

- 成功且通过已有核验导出门禁的记录才提供指标；失败、取消、未结束和不可信历史仍有一行，但指标为空。真实0保留。
- 不把失败记成0分；报告同时给出总运行数、有效数、失败/取消数。
- 按场景SHA、源码、物理/姿态、约束、初始模型、预算、并发、执行模式和算法参数/模型权重隔离；不同有效指标版本再拆组。
- 样本标准差需要至少2个有效值；同种子重跑不能当独立随机重复。关注unique_seed_count，不跨不同母场景随意汇总论文结果。
- 综合分沿用70%完成率、20%归一化收益、10%时效；耗时独立列出，严格耗时对照用单Worker。
- 工程采样核验通过仍不等于严格连续认证。
- 包不含原始场景或模型文件；这些按谱系和SHA另外分发。
