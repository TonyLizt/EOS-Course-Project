# 控制台与 Cesium UI/UX 修正

日期：2026-10-18。本轮为现有实验功能的局部调整，不修改算法、指标、物理约束或数据库；不 Push/PR，不操作用户 8765 服务。

## 比较与新增算法

- 原比较复选框没有覆盖全局 `input { width:100%; min-height:44px }`，造成全宽大控件；旧排序区只在混合模式显示，控件与名称的关联也不清楚。
- 使用紧凑分组卡片：16px 复选框紧邻算法名称，选中边框/背景、连续顺序编号及 28px 上下按钮在同一卡片内。标签本身提供更大的点击区域，保留键盘、焦点和可访问名称。
- 删除独立混合模式及其专属控件，只保留按算法、按实验。两种模式均可勾选结果和组内排序；切换模式保留选择，不改变原始数据。分组边界仍明确，不将某实验的结果移入另一个实验。
- 一键创建对照入口与模型下拉移至比较区域右上角，响应式换行；保留禁用、幂等和结果反馈。比较 API 的严格条件限制不变。
- 实验详情新增算法改为复选框加“添加所选算法”确认，使用注册算法默认参数，不再显示说明或参数入口。已加入算法禁用；Cesium 下方则完全不重复显示已加入算法。提交期间锁定控件、防重复提交，后台仍使用活动算法唯一约束。逐项新增失败保留已成功结果并显示错误，不改历史或正在运行的既有算法。

## Cesium 局部调整

只调整 Metrics 下实验算法区内部；已完成且可回放算法仅显示名称，当前回放用选中背景、边框及 aria-current 表达。运行中、失败和计划不可用仍保留必要状态。已加入卡片缩小内边距，三角为紧凑独立热区；新增列表取消固定高度及内部垂直滚动，使用原侧栏滚动。新增/移除后同一实验状态刷新两个区域。完整 Run 导航、Metrics/Intervals/Gantt 关联不变。

## Hide / Show Grid 根因与修复

原按钮已绑定 `visible`、`grid.hidden`、文字和 aria-expanded，不是缺少点击事件。真正的问题是 `#payloadSatelliteGrid { display:grid }` 覆盖浏览器默认 `[hidden]` 规则，隐藏了逻辑更新却没有隐藏画面。

增加 `#payloadSatelliteGrid[hidden] { display:none }`，同时隐藏网格提示。隐藏时销毁并清空仅用于子画面的排队渲染器，不销毁主 Viewer 或共享载荷 Viewer，不修改卫星/任务/时钟/跟随。`renderTile` 在隐藏时拒绝新子视图请求；恢复时保留选中及 2×2 状态，为所有卫星提交当前仿真时间快照，只在完整新帧提交后显示 Canvas，避免旧画面重新出现。暂停时恢复也会主动入队，不依赖时钟继续推进。

## 本轮实际验证

- 4 项交互纯函数测试、7 项既有时间轴测试及载荷渲染队列测试通过；JavaScript 语法和 diff 空白检查通过。
- 一次隔离真实 Chromium/Cesium 两星回归通过：两种比较的选择/排序、复选框尺寸、右上角对照创建、详情新增勾选/取消、Cesium 完成项名称和选中状态、无重复待添加算法、取消内部滚动、新增/移除后两区同步、选中 2×2 后隐藏/显示及新帧重新提交、原算法切换和 Gantt 导航。捕获页面错误为空。
- 另做比较区域实际截图复核；不重新运行多场景调度、不做长时 GPU 压测。数据使用已有隔离合成测试夹具，其测试认证注入不代表正式物理认证。

限制：排序限当前分组内部；新增使用默认参数，批量逐项提交而非跨算法原子事务；不保证隐藏状态跨完整算法页面导航保存。没有重新执行全面 WCAG 审计或实体触屏测试。此前的算法可用性、正式认证门禁及 legacy 历史兼容限制均保留。
