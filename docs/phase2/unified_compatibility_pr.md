## 修改目的

恢复小组既有场景与原 LAVIS 模型的可用性，解决 PR #25 之后公共姿态定义/来源规则变化与 CAABS 特有预筛选造成的不兼容。采用李泽同明确确认的旧课程仿真姿态合同，保留遮挡核验；不整体回滚主分支。

## 主要修改

- CAABS 工程预筛复用公共 candidate_exposure，与其他算法对齐；正式来源策略、公共约束与 Controller 独立核验保留。
- 明确识别已审查的旧生成源码合同，保留原场景/侧车 SHA，旧数据继续使用生成时的 TargetPointing 绝对 Euler 定义。
- 新 Nadir/四元数合同保留，不把新旧角度混用；旧合同不追溯套用新增 FOV/跟踪限制，导出明确记录姿态版本。
- 恢复原 LAVIS v1/v2/v3 权重登记，保持 manifest 和权重原字节；增加当前运行适配器身份冻结，保留特征/依赖/域/SHA 校验。
- API 与 Worker 共用模型/场景域判断，防止旧权重错误用于新版姿态场景。
- 更新 README、COURSE_SETUP、历史状态说明、组员交接及小型验收报告，补充算法预算口径。

## 范围与限制

- 不批量生成场景、不重新训练、不修改数据库模式、不删除或改写历史实验。
- 工程采样通过不是严格连续认证；未运行全部场景与算法的笛卡尔积，未形成新泛化性能结论。
- LAVIS仍要求完成率、earliest、默认约束、无地面站；权重与数据另行分发，不进入Git。
- MIP缺PuLP/CBC、PPO未接入可信模型的原有限制保持；完成率优先和自适应修复仍是初始排程模型。
- 合并更新后需正常重启后端；保留旧失败记录，重新创建实验验证，不删除锁。
