## 阶段 3–6：动态机会、覆盖、搜索与验证取舍

版本 1.1.0：公共构造器产生有界原始网格模板，所有插入仍由原始公共约束判定；4096 项模板 FIFO 缓存不保存最终解。
当前轮机会见证覆盖至多两颗可行卫星、每星两个位置；已验证见证用公共离散约束估算新增包造成的机会损失（仅内部估计，不承担任务核验）。
每层仅两个入围任务承担机会估计；资源/转向/正式效用增量仍参与报价。
候选按原始拥有星数、当前已探查拥有星数、截止期、时长及优先级排序；位置包含 earliest/latest/center 和转向余量后的原始网格边界。
真实多任务 Bundle、全局唯一 incumbent、完整中标重放、中标后重新报价均保留。

自适应压力 = 原始预选窗口数 / max(0.1s, 剩余搜索时间)：>200 时任务宽度 1、起点 1、窗口≤2、位置≤2、保护任务 1；>50 时任务宽度≤4、起点1；否则采用参数上限。阈值不读取场景身份。
多起点 1→2 在验证集上未表现稳定收益，默认保持1，但参数支持至4；可选 1→2 同星替换最多尝试64次，只接受严格增加完成数的完整公共重放，默认0。
验证表和最终选择以之后冻结记录为准；未观察 held-out 结果。
